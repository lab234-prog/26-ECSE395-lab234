# Playing With Sensors Lab
## Lab Objectives
1. Upload Code to ESP32 via PlatformIO
2. Fill out the Potentiometer code (potentiometer.cpp)
3. Test with PIN A1 as input
4. Fill out Voltage sensor code (voltage.cpp) to shift from reading raw data to reading the float value of estimated voltage
5. make and upload a video of the voltage code output
6. make a copy of the voltage code to make a touch sensor.
7. replace the potentiometer with the provided touch sensor
8. change the code to make the ESP32 turn a light on and signal a touch when touched, and turn off a light and signal when otherwise.
9. upload all code to github
10. reflection and submit repo
